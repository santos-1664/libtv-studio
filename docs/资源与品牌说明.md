# 资源与品牌说明

更新日期：2026-09-16

## 项目关系

LibTV Studio 是参照 LibTV 核心交互的非官方独立实现，与 LibTV 无隶属、授权或背书关系。本仓库不是 LibTV 官方产品或官方源码发布。当前项目名称保留参照对象名称，不表示获得该品牌的认可。

## 随仓库提供的界面资源

下表记录资源在代码中的实现位置；SVG、CSS 或代码内文案的形式本身不是第三方授权证明。

| 资源 | 实现位置 | 内容与用途 |
| --- | --- | --- |
| 首页产品插画 | `public/art/product.svg` | SVG 路径、形状、渐变与文字构成的香水瓶主题，用于创作模板入口。 |
| 首页风景插画 | `public/art/landscape.svg` | SVG 路径、形状与渐变构成的日落海边场景。 |
| 首页抽象插画 | `public/art/abstract.svg` | SVG 形状、渐变和滤镜构成的球体、圆环与几何场景。 |
| Agent 的六组示例插画 | `client/components/AgentWorkspace.tsx` 中的 `SkillArtwork`；`client/components/agent.css` | DOM、CSS 形状和渐变构成的场景、香水瓶、分镜纸、星球、画框与字样；噪声纹理由内嵌 SVG 滤镜绘制。 |
| 工作台标识与装饰 | `client/App.tsx`、`client/styles.css`、画布与 Agent 组件 | 文字、CSS 条纹、线条和几何装饰构成的界面元素。 |
| 首页创作模板 | `client/App.tsx` 中的 `templates` | 直接定义在源码中的产品广告、电影短片与视觉实验提示词，点击后创建可编辑文本节点。 |
| Agent Skill 与提示词 | `server/agent.ts` | 六个 Skill 的名称、描述、起始提示词及工具调用指令，作为应用功能代码提供。 |

三张首页 SVG 没有嵌入外部图片或引用远程资源，`dist/art/` 提供相应构建副本。仓库不附带个人生成结果、上传素材或历史项目。插画中的 **S O L**、**ÉCHO**、**EAU DE PARFUM** 是界面样例文案，用于表达商品创作场景，不构成商品销售或品牌背书。

上述模板和文案可在代码中编辑；本说明不将其标记为来自 LibTV 的官方素材，也不声称取得任何第三方品牌授权。贡献新增或替换资源时，请同步记录实际来源与适用许可。

## 第三方依赖与字体

通用界面图标来自 `lucide-react`。React、React Flow 及其他依赖属于第三方代码，其许可和必要版权通知见仓库的 [第三方声明](../THIRD_PARTY_NOTICES.md)，与界面示例资源的来源分开记录。

项目没有附带字体文件或远程字体加载；CSS 通过字体栈引用设备可用字体。若后续加入字体文件，需要同时补充相应来源及许可说明。
