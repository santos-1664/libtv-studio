# 模型接口接入说明

更新日期：2026-09-16

本源码包不包含 API Key、个人服务地址、已保存模型配置、数据库或主密钥。首次启动建立空白工作区，接收人需要在设置页填写自己的服务配置。文本与 Agent 使用 OpenAI 兼容接口，图片与视频支持百炼协议。

## 请求路径

```text
服务设置 → 本地模型检查 → 文本基地址 + /models
画布文本节点 → 本地持久化任务 → 文本基地址 + /chat/completions
Agent 输入 → 聊天 SSE → 校验工具参数 → 更新项目或提交生成
图片 / 视频节点 → 对应媒体协议 → 结果下载归档
```

文本请求采用 `Authorization: Bearer <API Key>`。只填写根地址时自动补 `/v1`；明确提供 `/v1`、`/compatible-mode/v1` 等路径时保留该路径，不重复添加 `/v1`。随后追加 `/models` 或 `/chat/completions`。

百炼兼容文本基地址的占位格式：

```text
https://<your-provider-host>/compatible-mode/v1
```

替换为服务控制台提供的实际地址。图片与视频的百炼配置填写业务空间 HTTPS 根地址，不附加 `/api/v1` 或 `/compatible-mode/v1`。使用相同 API Key 不意味着这些协议可以共用相同路径。

凭据仅由服务端使用，不放入 URL、不硬编码到源码或前端、不通过状态接口回传。接口失败时显示实际错误；SSE 中途断开时不会执行未接收完整的工具调用。

## 配置字段

| 用途 | 环境变量 | 设置接口字段 |
| --- | --- | --- |
| 文本与 Agent 基地址 | `TEXT_BASE_URL` | `textBaseUrl` |
| 文本与 Agent API Key | `TEXT_API_KEY` | `textKey` |
| 文本默认模型 | `TEXT_MODEL` | `textModel` |
| 图片协议与地址 | `IMAGE_PROVIDER`、`IMAGE_BASE_URL` | `imageProvider`、`imageBaseUrl` |
| 图片密钥与模型 | `IMAGE_API_KEY`、`IMAGE_MODEL` | `imageKey`、`imageModel` |
| 视频协议与地址 | `VIDEO_PROVIDER`、`VIDEO_BASE_URL` | `videoProvider`、`videoBaseUrl` |
| 视频密钥与模型 | `VIDEO_API_KEY`、`VIDEO_MODEL` | `videoKey`、`videoModel` |

`.env.example` 是无密钥模板。部署中已保存的加密设置优先于环境变量。首次填写服务时须提供有效密钥；之后在同一 origin（协议、域名和端口）下，输入留空可保留已存密钥。更换文本、图片或视频服务的 origin 时必须提供目标服务的新 API Key；不会将原密钥自动用于新来源。不同来源的已存地址也不会继承环境变量里的密钥。源码包不自带任何密钥。

## 首次配置流程

1. 启动应用，打开“设置 → 创作与对话”。填写自己的文本 API URL 和 API Key。
2. 点击“验证并获取模型”。该操作只读取目录，不保存配置或提交生成。
3. 选择账户实际可用的文本模型并保存。Agent 需要支持工具调用的模型。
4. 在图片与视频页分别选择协议并填写地址、API Key 和支持的模型。
5. 使用自己新建的项目验证文本请求和 Agent 工具调用，再按需要测试媒体生成。

`POST /api/models/check` 用 `textBaseUrl`、`textKey` 检查表单配置，返回 `{ models, checkedAt }`。保存使用 `PUT /api/settings`。`GET /api/models?kind=text` 读取本部署已保存的文本配置；`kind=image|video` 读取各自服务，并仅返回当前媒体适配器支持的模型。

“已配置”表示必需字段齐全。模型目录可读不能替代聊天、工具调用或媒体生成的实际验证。

## 百炼媒体

当前适配范围包括 `qwen-image-3.0` 和 `wan2.7-t2v` 等协议。模型名称是适配范围说明，不代表源码包内已有授权，实际可用模型以接收人的账户、地域和权限为准。

选择已支持的 Wan 默认文生视频系列、视频节点不显式指定模型且连接首帧时，会使用配套 `wan2.7-i2v-2026-04-25`。显式指定文生视频模型却连接图片时，界面要求调整选择。视频时长为 2–15 秒整数，图生视频需要且只接受一张有效首帧，比例跟随首帧。

协议细节见 [百炼接口调研](百炼接口调研.md)。视频理解尚未接入，上传视频仅代表将其作为本地项目素材保存。

## 空白启动与后续备份

本交付的 `data/` 仅有 `.gitkeep`。首次启动自动建表，并为新部署生成本地主密钥；Docker 将后续运行数据保存在独立命名卷中，没有开发者历史数据可恢复。

接收人开始使用后，备份自己的部署应保留数据库、媒体和配套 `.master-key`。若指定 `SETTINGS_ENCRYPTION_KEY`，恢复时需使用相同值。运行数据和密钥应与无凭据源码发布包分开管理。

开发阶段曾完成真实文本、图片、视频生成，Agent 脚本与分镜创建、指定镜头修改及重新生成，以及密钥不回填、留空保留已存密钥等交互验证。

开发阶段的 API Key、个人服务地址、项目标识、数据库、会话和生成媒体均不随包提供。清理发布副本不等于重新执行了真实模型或付费测试；具体源码检查范围见 [验收记录](验收记录.md)。
